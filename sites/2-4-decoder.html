2-4 Decoder

The 2 to 4 Decoder is a combinational digital circuit element that will drive an single bit in the output vector y to turn on based on the combination of whether the input a or b are turned on or not. A pretty iconic use of a decoder is for memory addressing decoding, where a certain word line is selected in a SRAM component.

Decoders themselves convert a binary code into a set of output signals, and they also do the inverse of digital encoding. Given any N input lines, there will be 2^(N) output lines for any given decoder.

Each bit of the output can be represented by a corresponding boolean expression:

y[0] = a' * b' where multiplication (or asterisks) represent the AND operation and apostrophes show the complement of that value

y[1] = a' * b

y[2] = a * b'

y[3] = a * b

The side block diagram form of the 2-4 Decoder is done in Xilinx Vivado using the IP generation tool. Note that I have not included a specific package download in my website to account for this, simply because it is likely that your toolset for your FPGA or other board will have an easier time optimizing and improving the efficiency given simply the Verilog code rather than a direct IP package. This also allows you to have more freedom in modifying or recreating such designs if you so desire to improve its implementation tailored to your needs.
