The 2-to-1 Multiplexer / Multiplexor / MUX

The 2-to-1 MUX / Multiplexer / Multiplexor is a device that allows either input A or B to be driven as its output based on the value of the signal pin provided. It is the basis for more complex devices such as 4-to-1 (or 8-to-1!) MUXes to enhancing full adder circuitry.

The general characteristic equation for a 2:1 (or 2-to-1) MUX is O = S'A + SB, assuming that A, B, S, and O are all one bit inputs and outputs.

However, the current Verilog code utilizes the wires to channel output, so the functional logic that this MUX implementation becomes a little more complex and abstract. Although it may be more simpler from a logic standpoint to use case statements or if-else statements, Verilog directly treats ternary operators like the assign statement to be modeled more accurately in hardware and try and give as accurate output as possible.
